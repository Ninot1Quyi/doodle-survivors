## 2. 画面中实际看到的内容

### 镜头与空间

- 第2秒1080p帧中，桥面、台阶、石柱有可见侧面；角色、花、纸片怪物基本竖直站立。角色并未跟着地面椭圆一起变矮。
- 地面纹理、水平展开的法阵、角色脚下暗投影负责表现纵深。法阵在画面中呈椭圆；竖直雷电与龙卷风有明显的垂直高度。
- 桥上栏杆、柱体侧面和平台边缘为实体厚度提供线索。单纯把整个2D画布压扁不会得到这些侧面。
- 六张时间帧中能看到地图与四名玩家群体的相对位置变化。画面不是固定中心人物上叠一层静止场景；镜头会随群体位置平移。仅凭这些抽帧不能证明具体的跟随缓动系数、FOV、精确俯角或自动缩放策略。
- 阴影的方向和落点连贯；前景物体、角色与后排怪物存在遮挡关系。轮廓线和白色纸边使密集战斗中的实体仍可分离。

### 时段与战斗阅读

| 大致时段 | 直接可见的阅读要点 |
|---|---|
| 0–10秒 | 四人群体靠近桥、水面和石柱；龙卷风、法阵、伤害数字密集并存，但人物轮廓仍竖直 |
| 10–20秒 | 群体位置转移，地图随之平移；大范围地面效果与空中物体的高度是两套表现 |
| 20–40秒 | 玩家分散，纸片小怪、飞行弹体、伤害数字各自运动；局部攻击动作仍可被看见 |
| 40–50秒 | 显著横向光束和密集数字，特效很繁忙；参考并不等于“全程极简、没有闪光” |
| 约50秒以后 | 转为游戏标题与角色展示片尾，不能把该段静态构图当成战斗镜头行为 |

### 对当前游戏的建议

1. 保留现有“地面Y投影 + 立面不压扁”的分离。研究开始时的 `k=.74`（后续 world16 改为 `.62`）是项目实现选择，**不是从参考反求出的精确角度**。
2. 所有攻击判定和对象锚点继续位于同一地面世界坐标；只把绘制高度与地面Y拆开。场域半径、刀弧、光束路径跟地面投影；角色、掉落印章、雷柱、龙卷风高度独立。
3. 若继续靠近参考，应优先补桥/石柱/平台的侧面、脚下投影、前后遮挡和相机平移。继续调一个全局Y比例无法替代这些结构。
4. 镜头改变后，固定地面落点做A/B，确认人物脚底、阴影中心、预警圈中心、实际命中中心仍重合。不要把高处悬浮的特效本体误当成地面判定中心。
5. 参考里的数字和特效密度很高；可借鉴实体轮廓清楚与空间分层，不必照抄数字数量或全部屏幕拥挤程度。

## 3. 音轨：实测与未验证边界

**已完成音轨提取和全段技术解码；本轮没有进行主观听审，不能声称已经听过、确认柔和、辨认具体乐器，或确定某个声音来自哪一款素材包。** `audition.html`提供完整原片与音轨控件，供后续实际播放比较。另通过本机HTTP页面在Chrome播放原视频前4秒及全部15个候选，WebAudio分析器对每项均检测到非零输出，记录在`browser-playback-validation.json`。这是浏览器播放管线验证，不是主观听审；没有声称实际听辨了音色。

FFmpeg `ebur128=peak=true` 对完整提取音轨的实测：

- 综合响度：**-14.4 LUFS**。
- 响度范围：**1.5 LU**。
- 真峰值：**-2.3 dBFS**。
- 原始媒体含AAC双声道音轨，48kHz；WAV只是解码容器转换，并非无损原始母带。

这些数值说明这份**社交视频成片混音**响度相对稳定且留有峰值余量。它们不足以证明“音色舒服”，也无法把音乐、武器、拾取和混音后处理分别归因。不要把-14.4 LUFS直接写成游戏主总线的强制目标。

本轮候选指标使用24kHz浮点解码、左右声道算术平均。表中的“4k高通比”是4kHz高通滤波后RMS与原RMS之比，用于粗略比较高频占比；它不是感知响度、不是严格频带能量积分，也不等于柔和评分。OGG解码可产生轻微超零峰，不能仅由此断言源录音已削波。

## 6. 最小接入建议与验收

以下为下一轮实现建议，本轮没有执行：

- 先只比较“普通出手、普通命中、击杀、拾取、升级、持续激光”六个高频/关键角色，不同时大换63种武器，让变化可归因。
- 先决定原始素材，再做同一目标响度下A/B；不要靠统一降音量或强低通，把所有声音混成模糊同一音色。低频占比也不能单独代表舒服。
- 一次高频普通命中只触发一个短主声，保留同材质2–3个作者原始变体；用事件密度与远近优先级约束同一时刻叠加。具体并发数和间隔需实战确认，不是从参考片反推。
- 书页/布料只承担它适合的纸面运动；不要把噪声尾巴硬塞成奖励音。奖励、升级和拾取应有独立识别性。
- 持续激光使用可持续的原始循环和短淡入淡出，检查整圈循环接缝；不要反复触发短尖锐单发来假装持续声。
- 分别试听单次、每秒3次重复、8类同时触发、30–60秒实战；同音量比较，记录“刺耳/浑浊/像撕纸/无触感/舒服”的具体反馈及对应文件。
- 使用耳机与扬声器至少各一次实际播放，再确认可接入。自动测量与成功解码不能替代这一步，也不代表用户已经认可声音。

## 7. 本轮结论

可立即使用的交付是：完整参考视频、原音轨、实际检查帧、15个带授权与哈希的原始候选、可本地播放的对照页。镜头最值得学的是**地面投影与竖直实体分离、真实厚度、贴地阴影、遮挡与跟随运动**。音频目前完成的是**原片数据核验、官方授权核验和候选整理**，不是完成了主观音色匹配或用户听审。
