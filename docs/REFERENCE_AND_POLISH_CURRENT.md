# 参考与本轮修复证据

参考：[SETO 的 Rakuworld 视频](https://x.com/Setodev92/status/2117031710537760795)。本轮检查了约 60 秒视频的概览抽帧及 8–9.5 秒连续帧；仅用于研究，没有将视频、图像或声音提取为游戏素材。

## 可以确认的画面特征

- 多个攻击同时存在，但光束、投射物与旋转武器各有连续轨迹；局部爆点和纸片轮廓承担主要辨识。
- 在检查片段中，场景参照物相对稳定。将此转译为本项目的改动：普通命中保持局部形变、颜色和碎纸，减少反复全局顿挫。这不是对参考游戏内部算法的推断。
- 手绘的线条、纸片边缘与世界物体共用视觉语言。本轮按照用户截图重做小铺、暂停页，以及永恒玫瑰和月牙盾；不是复制参考游戏资产。

## 声音证据与边界

用户对参考声音“舒服”、对本游戏“次次的破碎音刺耳”的体验是本轮主要依据。不能只凭总体频谱判断舒服与否。

- 旧 `pickup.ogg` 与 `lightning.ogg` 的能量经过 4 kHz 二阶高通后的占比约 7.7% 与 2.4%，高于新的温和接触素材；旧星星、弹珠和铃铛等仍直接或间接调用它们，是已核实的漏网调用。
- 本轮改掉这些重复调用，并为重复施法和拾取增加独立共享预算；保留开箱里的短暂明亮庆祝。检查覆盖真实别名解析、音频源数量、分组节奏与音频图连接参数。
- 参考视频前 52 秒的混合音轨（音乐与音效不能分离）相同高通能量指标约 12.4%，本身也含明显高频。因此“频率越低越舒服”并不成立；本轮重点是去掉反复碎裂的素材、减少叠音，并保留动作节奏。
- 这些是数字信号与代码检查，不等于已经完成主观试听验收，也不证明浏览器实时混音无峰值问题。

## 验证范围

机制检查覆盖推荐/候选、经验门槛、3 秒倒计时、开箱生命周期、全武器伤害/合成、护盾、轨迹结算及长局模拟。绘制函数通过原生 Canvas 生成受控图像，查看了玫瑰与月牙盾；该图像不是浏览器实机截图。

当前浏览器自动化连接不可用。小铺/暂停/设置等 CSS 改动尚未完成浏览器截图、手机布局与新版本实际混音验收，不能将这部分写成已验收。帧调度数字来自人工时间戳重放，详见 PERFORMANCE_CURRENT.md。
