## 02 手作卡纸版

共享上述玩法，通过 `?edition=paper` 选择（默认）。`?edition=adventure` 保留第一版画风。

- 所有 Canvas 精灵增加不规则白色剪边、下层牛皮纸边缘、纤维和蜡笔斑点。
- 场景底纸更温暖，保留原始水彩与彩铅绘制。
- 手写标题、胶带、纸页圆角与叠纸阴影；卡牌、HUD、手帐采用相同手作语言。
- 改善主角在龙卷风中被遮挡的可读性。

所有视觉元素均由前端 Canvas/CSS 绘制；未使用 image-gen 或抓取他人游戏素材。

## 2026-11-03 · 动作与场景打磨

- 环绕书本统一碰撞与图像中心，以人物上身为中心；加入人物前后深度排序、翻页、短星光尾迹。原先所有书本统一画在角色前方的方式已移除。
- 角色加入呼吸、步伐弹性、冲刺前倾、眨眼和有寿命的脚印；怪物按软体、飞行、步行、重型区分形变，蓄力下蹲和受击挤压共用姿态，修复浮空高度的运算优先级。
- 弧斩改成层叠纸刃，光束加入蓄力虚线和流动核心，基础弹体增加笔锋尾迹，雷击补上分叉与落点纹章，龙卷加入彩纸螺旋。
- 温室取消十字道路和方格铺地，改为弯曲花径、不规则花圃；遗迹取消直角街区。区域边缘在烘焙时柔和过渡。
- 六种区域分别增加对应的地表细节、成片植物、大小动物与环境微动；保持地形预烘焙、区域缓存和视野裁剪。
- 脚本与样式带资源版本号，防止浏览器继续显示旧版。
